# Predictia-succesului-campaniilor-de-jocuri-de-pe-Kickstarter
Proiectul construieste un set de date propriu cu peste 1000 de campanii de jocuri de pe Kickstarter si prezice, prin clasificare binara, daca o campanie va reusi sau va esua. Se folosesc doar informatii cunoscute la lansare: obiectivul in dolari, durata campaniei, zilele de pregatire, luna, lungimea titlului si a descrierii, si daca proiectul este din SUA. Variabilele cunoscute abia dupa lansare (suma stransa, numarul de donatori) sunt eliminate pentru a evita data leakage. Se compara un baseline (regresie logistica) cu Random Forest si gradient boosting, cu validare temporala.
